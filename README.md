## 广港IEPL到底是什么

广港IEPL，拆开就是“广港”加"IEPL"两部分。“广港”说的是线路走向——入口在广州机房，出口在香港机房；IEPL说的是这条线的类型：一条二层透传的物理私网链路，两端机房之间用专线光纤直连，中间不走公网BGP路由。

“二层透传”是理解这个产品的关键。普通公网访问要在几十个路由器之间逐跳转发，每一跳都增加延迟和丢包的概率；IEPL把以太网帧从广州端直接透传到香港端，中间没有公网路由参与。这也是商家宣传“不过墙”的来源——不经过公网路由，自然也不受公网侧QoS策略影响。广州到香港物理距离近，光缆走的就是华南这条最短路径，端内延迟才能压到1~2ms。

### 和IPLC有什么区别

IEPL和IPLC经常被放在一起说，两者都是点对点的国际私有专线，区别在底层技术：IPLC（International Private Leased Circuit）是更老的一代，基于TDM/SDH电信体系，接口是E1、E3、STM-1这类传统电信接口，带宽只能按固定等级选；IEPL直接给标准以太网接口，带宽可以灵活配置，接入现代网络设备不需要协议转换。成本上，10Mbps以上的电路，IEPL普遍比同等带宽的IPLC更划算，所以新的国际专线部署基本默认选IEPL。

| 对比项 | IEPL | IPLC |
| --- | --- | --- |
| 承载协议 | 以太网（二层） | TDM/SDH |
| 接口 | 1GE / 10GE / 100GE标准以太网 | E1、E3、STM-1等电信接口 |
| 带宽选择 | 1Mbps到100G灵活配置 | 固定TDM等级 |
| 新部署成本 | 10Mbps以上普遍更低 | 同等带宽下更高 |

## 广港IEPL的真实延迟有多少

华南地区是这条线收益最大的区域。广东、广西、福建、湖南南部这些地方，从深圳、广州、东莞测到出口的延迟普遍在2~4ms，部分测试能压到1ms出头，端内（广州到香港段）1~2ms，抖动控制在1ms以内。

华东（上海、江苏、浙江）要多走一段广州到华东的回程，通常在十几到二十几毫秒。华北（北京、天津、河北）在30~45ms之间。

比绝对数字更重要的是稳定性：因为不经过公网路由，这条线晚高峰基本不掉速。用过CN2 GIA或普通BGP中转的人应该体会过晚高峰掉速、抖动飙到几十毫秒的痛苦，这正是物理专线和公网优化线路的本质区别。

地区选择上有个简单规则：业务主体在华南，广港线闭眼选；在华东，沪日方向的IPLC物理路径更近（从华东访问普遍25ms上下）；华北用户两条线差距不大，稳定性都是专线水准。
